# DopaLess Android

Native Android digital-wellbeing companion built with Kotlin and Jetpack Compose.

## Project source
The complete Android Studio project is packaged as `DopaLess-project.zip`. Extract it and open the `DopaLess` folder in Android Studio.

## Build
- JDK 17
- Android SDK 35
- Minimum Android 8.0 (API 26)
- Run `gradle assembleDebug` from the project root.

The GitHub Actions workflow builds a debug APK after the project source has been added to this repository.
